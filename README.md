# 🌿 Wonder Frame - Image Gallery

Wonder Frame is a responsive and interactive **Nature & Travel Image Gallery** developed as **Task 1 of the CodeAlpha Internship Program**.

## ✨ Features

* Responsive image gallery
* Category-based image filtering
* Mountains, Beaches, Waterfalls, Forests, Flowers and Sunsets
* Smooth hover and zoom animations
* Full-screen image lightbox
* Modern nature-inspired design
* Mobile-friendly layout

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Explore the gallery and use the category buttons to filter images.
4. Click any image to view it in the lightbox.
